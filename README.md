NOSTRA – Fashion Store
NOSTRA is a beginner-friendly fashion e-commerce website developed using HTML, CSS and basic JavaScript. It features a beige, white and dark brown theme with a collection of everyday outfits.
Pages
Home: Introduction, featured products and shopping categories.
Collections: Product listing, search, category filters and price sorting.
Contact: Contact form with a demo confirmation message.
Features
Eight fashion products with images and prices.
Search products by name.
Filter products by Men and Women.
Sort prices from low to high or high to low.
Reset filters.
Add products to the shopping bag.
Increase and decrease product quantities.
Remove products from the cart.
Calculate the cart total.
Save cart items using browser localStorage.
Responsive layout for desktop and mobile.
Basic demo checkout and form interactions.
Technologies Used
HTML5
CSS3
JavaScript
How to Run
Download or clone the repository.
Open the project folder in Visual Studio Code.
Keep index.html, collections.html, contact.html, style.css and script.js in the same folder.
Open index.html using Live Server.
Navigate through the pages and test the available features.
Note
This is a front-end learning project. Checkout does not process real payments, and the contact and newsletter forms do not send real emails. Product images require an internet connection.
Project Goal
This project helps practise multi-page website development, CSS styling, JavaScript product filtering and basic shopping cart functionality.
